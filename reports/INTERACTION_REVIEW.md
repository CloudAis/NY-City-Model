# 第8部分：模型浏览与检查

2026-10-28，同一TypeScript/Vite/Cesium工程的inspection.html；原五个入口保留。

## 实际功能

- 全城概览、当前中心环绕、俯视、自由飞行、八个独立DEM受限地面检查；复位、返回选中、取消飞行/Esc。世界高度限制800—250000m只保护参考浏览，不宣称未知楼体避碰。飞向目标按真实水平包围范围取停点，缺失高度不造垂直盒。
- 鼠标旋转/平移/滚轮，WASD/QE、Shift慢速；速度随距离2—1200m/s，按真实elapsed积分，>1s帧间隙停止。地面1.4m/s、眼高1.7m、0.2m子步长；无桥面/楼内。键释放、焦点/可见性、触点取消、捕获丢失、横竖切换清空输入。
- 单指旋转、双指缩放/中心平移；双指时暂禁原生重复输入。实际测试为桌面Chromium软件WebGL和CDP模拟触点，非真实手机。
- 全市1,082,964记录静态ID/BIN/五区名称索引，2253条有来源名称/明确地址或别名；BIN非唯一。空结果、异常拾取、失效feature、快速异步查询/切换都保留场景。选中和悬停按原stableID，仅feature颜色条件高亮，不改共享材质。
- 面板分开来源、原始feet/未解规范楼高/基底、屋顶/立面未知、观测日/编辑日/抓取日和原页SHA。原始轮廓位置不能作为完整楼体已核验标签。
- 点位读取、全球水平测地两点量距；无同基准高度时空间/高差显示不可用。局部DEM可查同NAVD88水平/空间/有符号高差，取整米提示来源精度未知。
- 13图层开关含建筑轮廓、道路、人行道、分隔带、水、真实公园、交通层级、码头、铁路参考、入口、树点、原始轮廓、证据色；真实地形通过单独正高检查入口。隐藏、无数据、加载、失败分开，计数来自真实请求/瓦片解析，无定时假百分比。单GLB失败不阻断其余图层。
- 25真实坐标预设覆盖五区。最多12本地书签：位置/朝向/模式/范围/图层/画质/来源ID和保存时刻；局部相机通过ready握手并校验碰撞后恢复。JSON导入拒绝未知版本/非法字段并保留原书签。
- 统一中性固定光照、无雾/bloom/HDR/夸张玻璃；不支持日期太阳或夜景，lighting.datetime=null。保存时间不假装日照时间，America/New_York DST不适用。截图额外添加来源署名条，核心资源本地打包。

## 执行与结果

`npm test`：53项规则通过（最初沙箱禁止本地socket，保留失败日志；在允许本地HTTP监听的执行环境重跑通过）。`node tests/inspection-core.mjs`：六组逻辑检查，含20/60/144fps相同时间积分、坏拾取、量距、孤立桥面防吸附、书签验证及八个真实DEM合法spawn。合成桥面测试不在主场景。

`npm run build`：TypeScript与Vite通过，保留Cesium大chunk提示。`node tests/inspection-browser.mjs`：最终候选12组、25点、零页面/渲染错误，核心请求全部localhost（测试阻止外网）。包括实际合批源线点击/悬停、BIN/别名/地址/区筛选、取消/快速切换、键盘移动/焦点/触点取消、全球两点量距、书签拒绝导入/导出、真实DEM行走/两公园切换、图层释放、署名截图、刻意单瓦片404隔离、模拟手机双指/resize/收起。

既有页面回归：foundation8组（六区、轴、原始feature、正高缓冲释放）、landmarks6组、facades8组通过。截图已检查跨河真实道路/岸线、局部公园地面与窄屏；修复首次键计时、指针捕获误吞二次量距、异步资料等待、悬停按钮对比和局部HUD重叠。原始失败记录保留，不用计划冒充通过。

局限：当前世界无完整可信楼体/全球地面/桥面，禁止近地世界穿行；真实桥下/路面连续与碰撞未验收。没有真实触屏设备、物理GPU、其他浏览器、室内/地下/桥面漫游、太阳日期或夜景。软件WebGL帧率不能代表用户设备性能。

交付dist本地构建和nyc-stage78-inspection-overlay.zip；增量包明确需要旧stage4的datasets/buildings-city。运行方式与恢复步骤见README及包内START_HERE。包内CRC/SHA和组装离线浏览器结果另见stage8/package*.json。
