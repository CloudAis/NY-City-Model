# 纽约真实尺度 3D HTML

目标覆盖纽约五区。阶段1、2已保存，本轮用户授权阶段3：共用坐标、高程、真实地形/水面基础及配准验证；不自动启动阶段4。目标日期未指定，工作日期2026-10-27（Asia/Singapore），不编造交付期限。

真实位置、轮廓、朝向、尺寸分别保留来源。位置正确不代表屋顶或立面已复刻；未知不补默认高度，不生成虚构室内。默认外部建筑与可见城市环境。最终是浏览器HTML工程，另提供真实样区单文件预览，不能称全纽约完成版。

本轮产出：资产审计、可运行Cesium视口、官方轮廓原始样本、证据字段、可恢复下载器、规范化数据和下一阶段输入。全市完成度以实际统计为准，不把源服务总量当作已下载。

阶段4授权：使用已验证坐标与保存数据，五区建筑逐记录发布。严格模式仅生成证据允许的表示；缺少英尺种类、基底/屋顶/部件证据时不声称真实主体完成。可选的来源高度假设包络必须独立标记、显式开启、不计入可靠主体比例。
