# 真实性与精度

六个维度分别评价，不给“整栋真实”单一总分。位置/轮廓有官方来源仍待独立控制点/影像比对；高度有字段说明仍待同年代独立核验；屋顶和立面不得从高度字段推断。资料年代另列，未明确采集日保留null。

官方轮廓元数据对摄影测量更新给出约±2ft的来源精度说明，不能把它无条件套给手工绘制、占位、所有年份或本项目独立验证。官方模型基于2014摄影；OTI旧元数据有2016标记，取得的DCP包注明数据日期2018-08、发布2018-10-19，不能混为采集日或2026现状。LOD1.5省略穹顶/坡屋顶及附属结构等限制保留。

阶段1默认只显示真实轮廓测绘线。质量报告区分完整来源、有效数值、无独立核验、未知、占位、异常、失败，不拿来源网页更新时间代替观测日期。

阶段2取得全市来源记录。1,082,243条有通过基本数值检查的相对高度，721条未知（含1条异常）；独立核验位置、轮廓、高度均为0。34条占位不当实景展示，6项修复保留原记录/面积变化。屋顶、立面现状证据仍未知。

分区按BASE_BBL首位，尚未用边界独立复核每栋归属。服务总数、ID集、唯一数量、两端编辑时间已核对，但不构成事务快照；不能排除记录短时修改又改回。下载日不替代观测日，单建筑采集日仍null。
